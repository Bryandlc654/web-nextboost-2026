WordPress 7.1 "Mary Lou" es la última versión del CMS más popular del mundo, lanzada el 19 de agosto de 2026. Esta actualización se centra en cómo trabajas: navegar el admin, controlar diseños, colaborar con tu equipo y construir sitios sin depender tanto de plugins externos.

El nombre honra a Mary Lou Williams, pianista de jazz pionera que reinventó su sonido a lo largo de décadas — un reflejo del espíritu de innovación de esta versión.

Novedades principales de WordPress 7.1

Estilos responsive integrados

Ajusta la apariencia de cada bloque según el tamaño de pantalla (móvil, tablet, desktop) desde Estilos Globales o la configuración del bloque, sin escribir CSS personalizado. Incluye vista previa por viewport mientras editas.

Nuevo editor de medios

Un modal dedicado reemplaza el recorte inline anterior. Incluye recorte libre y por proporción, volteo horizontal/vertical, rotación precisa con snap, y edición de metadatos — todo desde el botón Crop que ya conoces.

Notes con @mentions

Deja comentarios en cualquier parte del contenido, no solo a nivel de bloque. Soporta texto enriquecido (negrita, cursiva, código, enlaces) y menciones con @ para notificar colaboradores. Ideal para equipos editoriales.

Bloques Playlist y Tabs

El bloque Playlist agrupa pistas de audio con forma de onda opcional. El bloque Tabs organiza contenido en paneles plegables, perfecto para FAQs, servicios o especificaciones sin saturar la página.

Rendimiento de imágenes

La compresión, redimensionado y generación de miniaturas ocurre en el navegador mediante WebAssembly (libvips), reduciendo carga del servidor y evitando límites de memoria PHP en subidas grandes. También añade soporte nativo para formatos AVIF, HEIC y HDR.

Otras mejoras que notarás al día a día

  • Barra de admin persistente: te acompaña en todos los editores con navegación consistente.
  • Editor iframed universal: experiencia más predecible entre el editor de entradas y el Site Editor.
  • Biblioteca de medios con scroll infinito: navega tus archivos sin paginación.
  • Accesibilidad mejorada: tooltips accesibles y mejor soporte para lectores de pantalla.

Herramientas para desarrolladores

  • API pública de iconos SVG para registrar colecciones personalizadas.
  • Abilities API ampliada para automatización e integraciones con IA.
  • Design System para interfaces admin más consistentes.
  • Breakpoints personalizables en theme.json y estilos para estados hover/focus/active en botones.

Cómo actualizar a WordPress 7.1

  1. Haz un backup completo de archivos y base de datos.
  2. Verifica la compatibilidad de tu tema y plugins.
  3. Ve a Panel → Actualizaciones y pulsa "Actualizar ahora".
  4. Prueba en staging si tu sitio tiene tráfico alto o ecommerce.
  5. Revisa formularios, checkout, login y páginas clave tras la actualización.

Preguntas frecuentes

¿Cuál es la última versión de WordPress?

WordPress 7.1 "Mary Lou", publicada el 19 de agosto de 2026. Es la versión activamente mantenida de la rama 7.1 y sucede a WordPress 7.0 (mayo 2026).

¿WordPress 7.1 es gratis?

Sí. WordPress sigue siendo software open source y gratuito. Solo pagas hosting y dominio. La actualización a 7.1 no tiene costo adicional.
